# Data

Place the case workbook here as `Network_modelling_assignment.xlsx`.

The workbook is course material provided by Kuehne+Nagel / HSLU and is not committed to this repository. The analysis reads three sheets:

| Sheet | Used for |
| --- | --- |
| `ShipmentData` | 6,923 shipments in 2023: date, origin, destination, weight |
| `Part1_Input` | distances, cross-dock set-up and processing costs, flat transport rate, supplier capacity |
| `Part2_Input` | LTL rate card by weight and distance band, FTL rate and capacity |
